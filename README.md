# «ВСНП помощь» для MAX

Бот помогает участникам готовить посты для группы `ВСНП_МОСКВА`. Пользователь нажимает **Новый пост**, отправляет текст и оригинальное фото в любом порядке, а бот возвращает готовый текст и изображение с фирменными элементами.

Исходная фотография не пересоздаётся: лица, люди, фон и сюжет сохраняются. Пакет `sharp` накладывает логотип из `assets/brand-logo.png`, текучие волны, тонкие линии звезды и цвета брендбука. Текст редактирует `внутренняя модель сервиса` через SmartAPI; изображение в SmartAPI не отправляется.

## Запуск локально

```bash
npm ci
copy .dev.vars.example .dev.vars
npm start
```

Для локального запуска переменные можно передать через окружение PowerShell. Сервис слушает `PORT` (по умолчанию `3000`). Проверка: `GET http://localhost:3000/health`.

## MAX и Cloud.ru

Продакшен-транспорт — MAX Webhook, а размещение — Cloud.ru Evolution Container Apps. Подробные шаги сборки образа, переменные, настройка HTTPS и подписка Webhook описаны в [CLOUD_RU.md](CLOUD_RU.md).

Нужны только секреты окружения:

```text
OPENAI_API_KEY
OPENAI_BASE_URL=https://api.smartapi.shop/v1
TEXT_MODEL=gpt-5.6-luna
MAX_BOT_TOKEN
MAX_WEBHOOK_SECRET
MAX_API_BASE_URL=https://platform-api2.max.ru
REQUIRED_HASHTAGS="#ВСНП_МОСКВА #Наставничество #Просвещение #Москва"
```

Webhook MAX должен вести на `https://YOUR-CLOUD-DOMAIN/webhook/max`. Подписка включает `message_created`, `message_callback` и `bot_started`.

`REQUIRED_HASHTAGS` добавляется к каждому результату после тегов пользователя. Его можно заменить на согласованный набор тегов группы без изменения кода.

## Безопасность и ограничения

- Секреты не хранятся в GitHub, Docker-образе или папке передачи.
- Доступ к подготовке постов открыт всем пользователям MAX-бота.
- Бот не публикует материалы автоматически в группу: он возвращает черновик в диалог для проверки.
- Состояние двух сообщений хранится в памяти контейнера и очищается через 15 минут. Для нескольких реплик потребуется Redis или другой внешний storage.
