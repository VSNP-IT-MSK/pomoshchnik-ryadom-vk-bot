# Бот «Помощник рядом» для VK

Бот принимает в сообщениях сообщества текст и оригинальную фотографию в любом порядке, улучшает текст и возвращает готовый материал в тот же чат. Исходная фотография сохраняется: люди, лица, фон и сюжет не перерисовываются. Поверх исходника добавляются логотип и фирменная графика ВСНП.

## Кнопки

- **Новый пост** — запускает сбор текста и фотографии.
- **Помощь** — объясняет, какие материалы нужно прислать.
- **Отмена** — очищает незавершённый материал.

Публикация на стене и cron отключены. `POST /cron/daily` намеренно отвечает `410 Gone`.

## Новый сценарий

1. Любой участник диалога нажимает **Новый пост**.
2. Отправляет готовый текст или тему и оригинальную фотографию в любом порядке.
3. Текст улучшает модель `gpt-5.6-luna` через SmartAPI.
4. Пакет `sharp` накладывает на исходное фото `assets/brand-logo.png`, волнообразные линии, мотив четырёхконечной звезды и фирменные цвета `#B88FFF`, `#7F74D8`, `#FFD21F`, `#29747D`, `#0C4746`.
5. Текст и брендированное фото отправляются обратно в сообщения сообщества.

Генерация новой сцены через `gpt-image-2` в этом сценарии не используется: она может изменить лица и сделать людей непохожими на оригинал.

Перед обработкой нужно запросить оригиналы фотографий в максимальном доступном разрешении, подтверждение права использования и согласия изображённых людей.

## Бесплатный Render

1. Подключите репозиторий `VSNP-IT-MSK/pomoshchnik-ryadom-vk-bot` в Render как Blueprint.
2. Задайте секреты:

```text
OPENAI_API_KEY
VK_GROUP_TOKEN
VK_CALLBACK_SECRET
VK_CONFIRMATION_CODE
VK_GROUP_ID
```

`OPENAI_BASE_URL` уже настроен на `https://api.smartapi.shop/v1`. Секреты не храните в GitHub, документации или handoff-папке.

3. В Callback API VK укажите `https://pomoshchnik-ryadom-vk-bot.onrender.com/`, версию `5.199` и включите `message_new`.
4. Включите сообщения сообщества и права токена на сообщения и фотографии. Права на стену не нужны.

Бесплатный Render может просыпаться до минуты после простоя.

## Сообщество

Бот работает в отдельном нейтральном сообществе **«Помощник рядом»**, ID `241549859`. Брендбук ВСНП используется только как источник фирменной графики для оформления фотографий.
