# Бот «Помощник рядом» для VK

Бот работает через кнопки в сообщениях сообщества и готовит материал прямо в чате: принимает текст и фотографию в любом порядке, создаёт текст через `gpt-5.6-luna`, выполняет дизайн-обработку изображения через `gpt-image-2` и возвращает результат в этот же чат. Новый сценарий не публикует материалы на стене и не запускает публикации по cron.

## Кнопки

- **Новый пост** — запускает сбор исходных данных. Текст/тема и фотография принимаются в любом порядке; после получения обоих элементов бот присылает готовый текст и дизайн в чат.
- **Помощь** — объясняет, какие текст и фотографию нужно прислать.
- **Отмена** — очищает незавершённый материал.

Старые текстовые команды и публикация на стену не входят в пользовательский сценарий. Wall/cron-код публикации удалён; endpoint `POST /cron/daily` намеренно отвечает `410 Gone`.

## Новый сценарий подготовки

1. Администратор нажимает **Новый пост**.
2. Отправляет тему или готовый текст и фотографию в любом порядке. Бот сохраняет первый полученный элемент и ждёт второй.
3. После получения обоих элементов бот создаёт/редактирует текст, выполняет дизайн-обработку фотографии и отправляет итог в сообщения сообщества.
4. Итог остаётся в чате для проверки и дальнейшего ручного использования. Автопубликации на стене и задания cron в этом сценарии нет.

Перед обработкой у заказчика нужно запросить оригиналы фотографий: файлы в максимальном доступном разрешении, без пересылки через сжатые мессенджеры, с подтверждённым правом использования и согласиями изображённых людей.

## Бесплатный деплой в Render

1. Создайте новый репозиторий на GitHub и загрузите эти файлы.
2. В Render выберите **New → Blueprint**, подключите репозиторий и подтвердите `render.yaml`.
3. В настройках сервиса задайте секреты:

```text
OPENAI_API_KEY
VK_GROUP_TOKEN
VK_CALLBACK_SECRET
VK_CONFIRMATION_CODE
VK_GROUP_ID
ADMIN_VK_IDS
```

`OPENAI_BASE_URL` уже настроен на `https://api.smartapi.shop/v1` по документации SmartAPI. Ключи не храните в репозитории. Бесплатный план Render может засыпать после периода без запросов, поэтому первый запрос после простоя может занять до минуты. Генерация GPT и запросы VK тарифицируются по правилам их провайдеров.

4. В настройках сообщества VK откройте «Работа с API → Callback API», укажите URL `https://pomoshchnik-ryadom-vk-bot.onrender.com/`, секрет и версию API `5.199`. Событие `message_new` должно быть включено. Код подтверждения из VK положите в `VK_CONFIRMATION_CODE`.
5. Включите сообщения сообщества и выдайте токен с правами на сообщения, фотографии и файлы. Права на стену для нового сценария не нужны.

Ежедневная публикация не настраивается: wall/cron-публикация удалена, а `POST /cron/daily` возвращает `410 Gone`.

## Что нужно настроить в VK

- Токен сообщества, а не пользовательский токен.
- `VK_GROUP_ID` — числовой ID без знака минус.
- `VK_CALLBACK_SECRET` и `VK_CONFIRMATION_CODE` — значения из Callback API.
- `ADMIN_VK_IDS` — ID пользователей через запятую.

## Новое сообщество

Бот рассчитан на отдельное нейтральное сообщество **«Помощник рядом»**. Создайте его в VK вручную один раз, затем включите сообщения сообщества и Callback API. После создания VK покажет ID сообщества и позволит выпустить токен сообщества. В коде нет привязки к ВСНП: брендбук используется только как визуальный источник для стилизации изображений и редакционной логики.
