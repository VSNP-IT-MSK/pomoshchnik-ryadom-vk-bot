# Бот «Помощник рядом» для VK

Бот работает через кнопки в сообщениях сообщества: создаёт текст через `gpt-5.6-luna`, генерирует визуал через `gpt-image-2`, загружает изображение в VK и при подтверждении администратора публикует запись на стене.

## Кнопки

- **Создать черновик** — бот просит тему и присылает черновик с изображением в сообщения сообщества.
- **Опубликовать пост** — бот просит тему и публикует запись. Доступно только ID из `ADMIN_VK_IDS`.
- **Пост дня** — публикует пост дня. Доступно администратору.
- **Помощь** и **Отмена** — управляют сценарием подготовки поста.

Команды `/post тема`, `/publish тема` и `/daily` поддерживаются временно для совместимости.

## Бесплатный деплой в Render

1. Создайте новый репозиторий на GitHub и загрузите эти файлы.
2. В Render выберите **New → Blueprint**, подключите репозиторий и подтвердите `render.yaml`.
3. В настройках сервиса задайте секреты:

```text
OPENAI_API_KEY
VK_GROUP_TOKEN
VK_CALLBACK_SECRET
VK_CONFIRMATION_CODE
VK_GROUP_ID
ADMIN_VK_IDS
CRON_SECRET
```

`OPENAI_BASE_URL` уже настроен на `https://api.smartapi.shop/v1` по документации SmartAPI. Ключи не храните в репозитории. Бесплатный план Render может засыпать после периода без запросов, поэтому первый запрос после простоя может занять до минуты. Генерация GPT и запросы VK тарифицируются по правилам их провайдеров.

4. В настройках сообщества VK откройте «Работа с API → Callback API», укажите URL `https://<имя-worker>.<аккаунт>.workers.dev/`, секрет и версию API `5.199`. Событие `message_new` должно быть включено. Код подтверждения из VK положите в `VK_CONFIRMATION_CODE`.
5. Включите сообщения сообщества и выдайте токен с правами на сообщения, фотографии и стену.

Для ежедневного запуска используйте GitHub Actions или внешний cron-сервис, вызывающий `POST /cron/daily` с заголовком `Authorization: Bearer <CRON_SECRET>`.

## Что нужно настроить в VK

- Токен сообщества, а не пользовательский токен.
- `VK_GROUP_ID` — числовой ID без знака минус.
- `VK_CALLBACK_SECRET` и `VK_CONFIRMATION_CODE` — значения из Callback API.
- `ADMIN_VK_IDS` — ID пользователей через запятую.

## Новое сообщество

Бот рассчитан на отдельное нейтральное сообщество **«Помощник рядом»**. Создайте его в VK вручную один раз, затем включите сообщения сообщества и Callback API. После создания VK покажет ID сообщества и позволит выпустить токен сообщества. В коде нет привязки к ВСНП: брендбук используется только как визуальный источник для стилизации изображений и редакционной логики.
