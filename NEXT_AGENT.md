# Передача проекта следующей нейросети

Рабочая копия проекта находится в этой папке. Секреты намеренно исключены.

## Что уже сделано

- Создано VK-сообщество «Помощник рядом», ID `241549859`.
- Развёрнут Node.js-сервис в Render.
- Настроен VK Callback API и приём `message_new`.
- Текст генерируется моделью `gpt-5.6-luna` через SmartAPI.
- Изображение генерируется моделью `gpt-image-2` через SmartAPI.
- В `index.js` добавлен интерфейс VK-клавиатуры вместо основного сценария с командами.

## Важные настройки

Адрес SmartAPI должен быть задан в Render строго так:

```text
OPENAI_BASE_URL=https://api.smartapi.shop/v1
```

Без него сервис отправляет ключ не в тот API и отвечает ошибкой авторизации. Значения `OPENAI_API_KEY`, токена VK, callback secret и confirmation code не находятся в этой папке и должны оставаться только в Render/VK.

## Что проверить первым

1. Открыть сообщения сообщества в VK.
2. Нажать **Создать черновик**.
3. Отправить тему обычным текстом.
4. Убедиться, что бот прислал текст и изображение.
5. Проверить **Опубликовать пост** только на тестовой теме: действие создаёт реальную запись на стене.

Если генерация не проходит, открыть Render Logs и сопоставить ошибку с этапом: SmartAPI, загрузка фото в VK или публикация на стене.
