# Передача проекта следующему агенту

Репозиторий `VSNP-IT-MSK/pomoshchnik-ryadom-vk-bot` содержит код, который переносится с VK/Render на MAX/Cloud.ru. Текущая ветка добавляет MAX Webhook и Docker-образ; секреты в репозитории отсутствуют.

## Что уже сделано

- Добавлена нормализация `message_created` и `message_callback` MAX.
- Добавлены кнопки MAX: «Новый пост», «Помощь», «Отмена».
- Отправка текста и изображений переведена на `platform-api2.max.ru`.
- Исправлен баг `sharp` на маленьких фото: логотип ограничивается размерами исходника.
- Добавлены `Dockerfile`, `.dockerignore`, `CLOUD_RU.md` и переменные MAX.
- Имя бота в коде: «ВСНП помощь». Обязательные теги задаются через `REQUIRED_HASHTAGS`.

## Что осталось для боевого запуска

1. Пользователь должен войти в Cloud.ru и создать Container App из образа.
2. Нужен токен MAX-бота и секрет Webhook. Их следует ввести только в переменные Cloud.ru.
3. После получения HTTPS URL выполнить команду подписки из `CLOUD_RU.md`.
4. Проверить `GET /health`, затем отправить в MAX тестовый текст и оригинальное фото.

## Правила работы

- Не коммитить `MAX_BOT_TOKEN`, `MAX_WEBHOOK_SECRET`, `OPENAI_API_KEY` и приватные URL.
- Фото только оформляется локально, не генерируется заново.
- Бот готовит черновики для всех пользователей, но сам не публикует их в группу.
- При изменении MAX API сверяться с https://dev.max.ru/docs-api.
