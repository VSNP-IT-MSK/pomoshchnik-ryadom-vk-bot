# Передача проекта следующей нейросети

Рабочая копия проекта находится в этой папке. Секреты намеренно исключены.

## Что уже сделано

- Создано VK-сообщество «Помощник рядом», ID `241549859`.
- Развёрнут Node.js-сервис в Render.
- Настроен VK Callback API и приём `message_new`.
- Текст улучшается моделью `gpt-5.6-luna` через SmartAPI.
- Фотография не генерируется заново: исходник обрабатывается пакетом `sharp`, чтобы сохранить лица, людей, фон и сюжет.
- Поверх исходника накладываются `assets/brand-logo.png`, волнообразные линии, мотив четырёхконечной звезды и цветовые акценты из брендбука.
- В `index.js` добавлен интерфейс VK-клавиатуры с кнопкой **Новый пост** вместо основного сценария с командами; пользоваться ботом могут все участники диалога.
- Документация описывает новый сценарий: текст и фото принимаются в любом порядке, результат возвращается в чат.
- Публикация на стену удалена; `POST /cron/daily` отвечает `410 Gone`.

## Важные настройки

Адрес SmartAPI должен быть задан в Render строго так:

```text
OPENAI_BASE_URL=https://api.smartapi.shop/v1
```

Рабочий URL сервиса и Callback API: `https://pomoshchnik-ryadom-vk-bot.onrender.com/`.

Без него сервис отправляет ключ не в тот API и отвечает ошибкой авторизации. Значения `OPENAI_API_KEY`, токена VK, callback secret и confirmation code не находятся в этой папке и должны оставаться только в Render/VK.

## Что проверить первым

1. Открыть сообщения сообщества в VK.
2. Нажать кнопку **Новый пост**.
3. Отправить тему/текст и фотографию в любом порядке.
4. Убедиться, что обычный участник без специального списка администраторов дождался обоих элементов и получил текст с дизайн-обработанным фото в тот же чат.
5. Убедиться, что `POST /cron/daily` возвращает `410 Gone`, а стеновая публикация не вызывается.

Если генерация не проходит, открыть Render Logs и сопоставить ошибку с этапом: Callback API, SmartAPI, загрузка фото в сообщения или выдача результата в чат.

## Что продолжать дальше

- При необходимости доработать дизайн-обработку исходников под формат VK: фирменная палитра, текучие формы, мотив четырёхконечной звезды и чистая зона под заголовок. Не подключать генерацию новой сцены, если требуется сохранить узнаваемость людей.
