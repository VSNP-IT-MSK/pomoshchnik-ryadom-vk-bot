# «ВСНП помощь»: MAX-бот для подготовки постов

## Назначение

Бот «ВСНП помощь» помогает участникам готовить материалы для редакционной логики `ВСНП_МОСКВА`, не нагружая администраторов ручной вычиткой каждого черновика. Бот доступен всем пользователям, не публикует на стену автоматически и возвращает результат в диалог MAX.

## Сценарий

1. Пользователь нажимает кнопку **Новый пост**.
2. Отправляет текст и исходное фото в любом порядке.
3. Бот запоминает пару `chat/user` до 15 минут.
4. SmartAPI с моделью `gpt-5.6-luna` редактирует текст в стиле группы: конкретный заголовок, факты, польза читателю, мягкий призыв и обязательные тематические хэштеги.
5. `sharp` оформляет исходник локально: логотип, волны, цветовые акценты и знак звезды. Люди, лица, фон и композиция не перерисовываются.
6. Бот отправляет пост и изображение с кнопками **Новый пост**, **Помощь**, **Отмена**.

## MAX API

- Webhook: `POST /webhook/max`.
- События: `message_created`, `message_callback`, `bot_started`.
- Отправка: `POST /messages?chat_id=...` или `?user_id=...`.
- Фото: `POST /uploads?type=image`, затем вложение `{"type":"image","payload":{"token":"..."}}`.
- Авторизация: заголовок `Authorization: <MAX_BOT_TOKEN>`.
- Webhook secret проверяется через `X-Max-Bot-Api-Secret`.

## Размещение

Целевой хостинг — Cloud.ru Evolution Container Apps. Контейнер слушает `0.0.0.0:$PORT`, рекомендуется один постоянно работающий экземпляр для стабильного Webhook. Старые настройки VK/Render удалены из новой конфигурации.

## Ограничения

Память контейнера используется для незавершённых черновиков. При перезапуске черновики исчезают. Бот не заменяет редактор: перед публикацией нужно проверить даты, имена, ссылки и согласие на использование фото.
