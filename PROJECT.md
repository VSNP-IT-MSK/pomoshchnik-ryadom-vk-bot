# Помощник рядом: проект VK-бота

## Назначение

«Помощник рядом» — отдельное VK-сообщество с ботом для подготовки и публикации полезных постов. Название и публичная оболочка не привязаны к ВСНП. Брендбук ВСНП Москва применяется только как визуальная и редакционная опора для создаваемых материалов.

Бот рассчитан на администратора сообщества. Он принимает тему, создаёт текст на русском языке, формирует визуал в фирменной стилистике, отправляет черновик в сообщения сообщества или публикует готовую запись на стене.

## Аудитория и стиль публикаций

Посты адресованы подросткам и молодым людям, наставникам, родителям и специалистам помогающих профессий в Москве. Тон — спокойный, конкретный, бережный, без канцелярита и рекламных обещаний.

Базовая структура поста:

1. Короткий заголовок.
2. Кому и чем полезна тема.
3. Одна практическая мысль, шаг или условие.
4. Снятие типичного барьера.
5. Вопрос или мягкий призыв к диалогу.
6. От двух до четырёх тематических хэштегов.

## Сценарий работы в VK

В сообщениях сообщества администратор видит постоянную клавиатуру:

- **Создать черновик** — бот спрашивает тему, затем присылает текст и изображение в чат.
- **Опубликовать пост** — бот спрашивает тему, создаёт материал и публикует его на стене.
- **Пост дня** — публикует подготовленный ежедневный сюжет.
- **Помощь** — напоминает сценарий работы.
- **Отмена** — очищает ожидаемую тему.

Текстовые команды `/post`, `/publish`, `/daily` остаются только для совместимости со старой настройкой. Основной интерфейс — кнопки.

## Генерация текста и визуала

- Текст: `gpt-5.6-luna` через SmartAPI.
- Изображение: `gpt-image-2` через SmartAPI.
- Endpoint: `https://api.smartapi.shop/v1`.
- Размер изображения: `1024x1024`.

Промпт визуала включает палитру `#B88FFF`, `#7F74D8`, `#FFD21F`, `#29747D`, `#0C4746` и белый, текучие линии, волнообразные формы, мотив четырёхконечной звезды, много воздуха, реальных людей и естественный свет. В изображениях нет читаемого текста, водяных знаков и чужих логотипов.

## Оригинальные фотографии: что нужно запросить

До запуска постоянной рубрики нужно запросить у заказчика оригинальные фотографии, которые можно законно использовать: мероприятия, участники, наставники, образовательные пространства и городской контекст. Нужны исходники в максимальном разрешении, без пересжатия мессенджерами, с подтверждённым правом публикации и согласием изображённых людей.

Эти фотографии не следует публиковать как есть. Для каждой серии потребуется дизайн-обработка: кадрирование под формат VK, коррекция света и цвета, адаптация фирменной палитры, добавление текучих графических форм и чистой зоны под заголовок. Исходники нужно хранить отдельно от итоговых публикаций.

## Техническая схема

```text
VK Callback API -> Render Web Service -> SmartAPI
                                     -> VK Photos API
                                     -> VK Messages / Wall API
```

Основные файлы:

| Файл | Роль |
| --- | --- |
| `index.js` | логика webhook, кнопок, генерации, загрузки изображений и публикации |
| `server.js` | адаптер Node.js для запуска на Render |
| `render.yaml` | конфигурация Render |
| `brand-guidelines.md` | краткая выжимка брендбука для промптов |
| `README.md` | инструкция запуска и настройки |

## Развёртывание

Сервис размещён на бесплатном Render: `https://pomoshchnik-ryadom-vk-bot.onrender.com`.

В Render должны быть сохранены переменные:

```text
OPENAI_API_KEY
OPENAI_BASE_URL=https://api.smartapi.shop/v1
TEXT_MODEL=gpt-5.6-luna
IMAGE_MODEL=gpt-image-2
VK_GROUP_TOKEN
VK_GROUP_ID
VK_CALLBACK_SECRET
VK_CONFIRMATION_CODE
ADMIN_VK_IDS
CRON_SECRET
```

Секреты не добавляют в GitHub, документацию или папку передачи проекта. В VK включены сообщения сообщества и событие Callback API `message_new`.
